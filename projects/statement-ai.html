Overview

Statement AI is a personal-finance analysis platform. A user uploads a bank statement, the system extracts and categorizes every transaction, computes financial metrics, and presents them through dashboards, searchable tables, charts and an AI assistant.

It supports single statements as well as combined analysis across multiple accounts, so income, spending, savings, recurring commitments and unusual transactions are visible without manual spreadsheet work.

My contributions

  • Owned the product end-to-end: document processing, structured financial-data extraction, agent tools, backend APIs, and subscription/payment workflows.
  • Designed the document-processing pipeline for PDF, CSV and Excel statements, including metadata extraction (bank, account, opening and closing balance).
  • Built the AI categorization layer: debit/credit, merchant versus person-to-person, clean counterparty names, categories and subcategories.
  • Implemented the data-grounded chatbot with restricted, user-scoped tools that query the user's own transactions.
  • Built the FastAPI backend with authenticated REST endpoints, PostgreSQL models and Alembic migrations.
  • Integrated Stripe checkout and webhooks with plan quotas, plus a separate admin console for staff.

Achievements

  • Optimized the processing pipeline from ~15–21 minutes down to about 45 seconds.
  • Live in production at statementai.io.
  • Combined-statement analysis removes duplicate rows and detects transfers between a user's own accounts, so moving money between accounts does not inflate income or spending.
  • Access boundaries enforced per user: chat tools can only reach the selected analysis, and password-reset responses never reveal whether an email is registered.

Top things to know

AI categorization

Interprets descriptions to assign category and subcategory, with consistent labels for repeated merchants and special handling for transfers, salary, refunds, taxes and fees.

Financial dashboard

Income, spending, savings rate, monthly trends, top merchants, recurring charges, weekday patterns and statistically unusual transactions.

Multi-statement analysis

Combine several accounts into one view with deduplication and internal-transfer correction.

Transaction explorer

Sort, paginate and filter by date, type, category and merchant status, with CSV export on eligible plans.

Data-grounded assistant

Natural-language questions answered from the user's computed summary and transaction data, not generic advice.

Plans and billing

Configurable quotas for files, combined statements, chat questions and export, enforced on the backend.

Admin console

Customer list, plan and limit changes, usage and payment visibility, and business metrics such as signups and conversion.
